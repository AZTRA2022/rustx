A rustx project is an ordinary cargo project, so cargo does most of the work.
What rustx adds is a command that writes a project, one that rebuilds when you
save, a build that names the executable, and an editor extension that shows
errors at the position you wrote.

```sh
cargo install rustx-cli      # rustx new, dev, build, run
```
