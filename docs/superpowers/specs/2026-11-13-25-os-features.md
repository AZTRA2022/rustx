# 25 additional OS features

> Validated with the user on 2026-11-13. Not yet implemented — dispatch
> only after the in-flight OS-completion work on `crates/rustx-os`
> (macOS stubs, Linux window-control threading) has landed, since both
> touch the same files.

**Scope:** `crates/rustx-os`, one new or extended module per theme
below, following the crate's existing pattern — one file per OS under
`src/<os>/`, a cross-platform facade file directly under `src/`, a
named `Err(OsError::Unsupported(...))` refusal (never a silent no-op)
for anything genuinely not implementable on a given platform, and a
test per behavior that can be tested (`crates/rustx-os/tests/*.rs`).

## Taskbar / dock integration
1. Taskbar progress indicator (Windows `SetProgressState`; macOS dock
   progress; Linux best-effort or a named refusal).
2. Badge / unread count on the taskbar or dock icon.
3. Jump list (Windows) / dock menu (macOS) / equivalent.
4. Flash-for-attention (flash taskbar icon / bounce dock icon).
5. Multi-monitor enumeration (displays, resolution, work area).

## System state
6. Dark/light theme detection, plus live-change notification.
7. Battery/power status (level, charging, low-power mode).
8. Idle time / screen-lock state.
9. Network connectivity status (online/offline, connection type).
10. Locale & timezone.
11. Display scaling / DPI.

## Input & devices
12. Audio device enumeration, default device, volume get/set.
13. Bluetooth paired-device listing.
14. Drag-and-drop: accept files dropped onto the window.
15. Drag-out: let the app start a native drag of a file to the OS.

## Files & security
16. Native color picker (eyedropper).
17. Recent-documents registration (Explorer "Recent" / macOS "Open
    Recent").
18. Secret storage: a small key-value store over Credential Manager /
    Keychain / libsecret.
19. File-type association registration (double-click a file opens
    this app).
20. "Reveal in file manager" for a given path.

## Notifications & tray
21. Interactive notification action buttons (not just a message).
22. Tray context menu with routed clicks — check `tray.rs` first,
    this may already exist.

## Misc
23. Printing (send content to the system print dialog).
24. Screenshot of a region or a window.
25. Native About panel (a macOS convention; trivial elsewhere).
